## 目标函数

### Q1：

- **L1范数**：$$||x||_1 = \sum_{i=1}^{n}|x_i|$$，$$SAD(x_1,x_2) = \sum_{i=1}^{n}|x_{1i}-x_{2i}|$$，即：向量中所有元素的绝对值之和（曼哈顿距离），比如空间中一点（1，-2，3），它与原点构成的向量的范数就是：$$1+2+3 = 6$$
- **L2范数**：$$||x||_2 = \sqrt{\sum_{i=1}^{n}x_i^2}$$，$$SSD(x_1,x_2) = \sqrt{\sum_{i=1}^n(x_{1i}-x_{2i})^2}$$，即：衡量向量大小的方法，也就是向量的模（欧几里得距离），比如空间中一点（1，-2，3），它与原点构成的向量的范数就是：$$\sqrt{1^2+(-2)^2+3^2} = \sqrt{14}$$

### Q2：

- 首先要了解L1损失和L2损失的计算：就是对应的范数（或平方）的均值
  - $$MAE =Loss_{L_1} = \frac{1}{N}||e||_1 = \frac{1}{N}\sum_{i=1}^{N}|y_{pred_i}-y_{true_i}|$$
  - $$MSE = Loss_{L_2} = \frac{1}{N}||e||_2^2 = \frac{1}{N}\sum_{i=1}^{N}(y_{pred_i}-y_{true_i})^2$$


- 在实际的计算中：一般的尺寸是（B，C，H，W）即（批量数，通道，高度，宽度），将原图像（**有雨图像**）的张量经过卷积和池化等一系列处理后（下采样，上采样，归一化等等，同时保持输出图像尺寸最终与原始图像尺寸一致），利用输出的（B，C，H，W）来与**真实无雨图像**（不是原来的有雨图像）的（B，C，H，W）进行计算得到L1损失和L2损失，并通过我们的目的和输出图像实际效果调整两个损失的权重，最终用L1损失乘以L1权重加上L2损失乘以L2权重得到总损失
- L1和L2损失在该任务中的计算可以写成以下形式：（对每个像素的每个属性（B，C，H，W）进行残差平方或残差绝对值的计算，再把这些值累加起来，除以总量（B x C x H x W））
  - L1损失（MAE）：$$\text{MAE} = \frac{1}{B \times C \times H \times W} \sum_{b=1}^{B} \sum_{c=1}^{C} \sum_{h=1}^{H} \sum_{w=1}^{W} \left| y_{\text{pred}}(b, c, h, w) - y_{\text{true}}(b, c, h, w) \right|$$
  - L2损失（MSE）：$$\text{MSE} = \frac{1}{B \times C \times H \times W} \sum_{b=1}^{B} \sum_{c=1}^{C} \sum_{h=1}^{H} \sum_{w=1}^{W} \left( y_{\text{pred}}(b, c, h, w) - y_{\text{true}}(b, c, h, w) \right)^2$$
  - L1损失对**细节**更敏感，因为他是**线性惩罚+梯度恒定**，它的惩罚按比例增长，使大残差区域不会成为首要消除目标，而是与小残差区域一起优化，并且它的梯度总是+-1，不会因为残差大小而有不同的调整幅度，从而使细节得以保留（纹理等特征）
  - L2损失对**平滑**更敏感，因为他是**非线性惩罚+梯度变化**，它的惩罚按按二次曲线变化，使残差大的部分相较于残差小的部分进一步放大，同时它的梯度是2e，残差越大，调整幅度越大，这样会使大残差区域逐渐向小残差区域靠近，也就是优先优化大残差，从而使图像看起来更平滑

## 评估指标

### Q1：

- 首先要了解PSNR和SSIM

  - PSNR的公式（我寻思题里面也没给啊）：$$\text{PSNR} = 10 \times \log_{10}\left( \frac{\text{MAX}^2}{\text{MSE}} \right)$$

  - SSIM用来衡量图片的失真程度（或两张图片的相似程度），是在**单个像素内（只涉及到B，C）**，对三个组件（**亮度，对比度，结构**）进行的乘积计算（C中的通道单独进行以下计算（如R，G，B通道））

    - 亮度：$$l_{b,c} = \frac{2\mu_{x,b,c} \mu_{y,b,c} + C_1}{\mu_{x,b,c}^2 + \mu_{y,b,c}^2 + C_1}$$（灰度的均值）

    - 对比度：$$c_{b,c} = \frac{2\sigma_{x,y,b,c} + C_2}{\sigma_{x,b,c}^2 + \sigma_{y,b,c}^2 + C_2}$$（灰度的标准差）

    - 结构：$$s_{b,c} = \frac{\sigma_{x,y,b,c} + C_3}{\sigma_{x,b,c} \sigma_{y,b,c} + C_3}$$（灰度的协方差与标准差的比值）

    - SSIM：$$\text{SSIM} = \frac{1}{B \times C} \sum_{b=1}^{B} \sum_{c=1}^{C} \left[ {l_{b,c}}^α \cdot {c_{b,c}}^β \cdot {s_{b,c}}^γ \right]$$（多通道计算后求平均）

    - **符号说明如下**

    - | 符号                 | 说明                                                         |
      | -------------------- | ------------------------------------------------------------ |
      | B                    | 批量大小（样本数），\(b=1,2,...,B\)为批量索引                |
      | C                    | 通道数（如 RGB 图像\(C=3\)），\(c=1,2,...,C\)为通道索引      |
      | \(x_{b,c,h,w}\)      | 第b个样本、第c通道、\((h,w)\)位置的预测图像像素值            |
      | \(y_{b,c,h,w}\)      | 对应位置的真实图像像素值                                     |
      | \(\mu_{x,b,c}\)      | 第b个样本、第c通道的预测图像像素均值，计算公式：\(\mu_{x,b,c} = \frac{1}{H \times W} \sum_{h=1}^H \sum_{w=1}^W x_{b,c,h,w}\) |
      | \(\mu_{y,b,c}\)      | 对应通道的真实图像像素均值（计算方式同\(\mu_{x,b,c}\)，将x换为y） |
      | \(\sigma_{x,b,c}^2\) | 第b个样本、第c通道的预测图像像素方差，计算公式：\(\sigma_{x,b,c}^2 = \frac{1}{H \times W - 1} \sum_{h,w} (x_{b,c,h,w} - \mu_{x,b,c})^2\) |
      | \(\sigma_{y,b,c}^2\) | 对应通道的真实图像像素方差（计算方式同\(\sigma_{x,b,c}^2\)，将x换为y） |
      | \(\sigma_{x,y,b,c}\) | 第b个样本、第c通道的预测与真实图像协方差，计算公式：\(\sigma_{x,y,b,c} = \frac{1}{H \times W - 1} \sum_{h,w} (x_{b,c,h,w} - \mu_{x,b,c})(y_{b,c,h,w} - \mu_{y,b,c})\) |
      | \(C_1\)              | 常数项，\(C_1 = (K_1 \cdot L)^2\)（\(K_1=0.01\)，L为像素值范围） |
      | \(C_2\)              | 常数项，\(C_2 = (K_2 \cdot L)^2\)（\(K_2=0.03\)，L为像素值范围） |
      | \(C_3\)              | 常数项，\(C_3 = C_2/2\)                                      |
      | α                    | 亮度的权重，放在指数位置，通常取1                            |
      | β                    | 对比度的权重，放在指数位置，通常取1                          |
      | γ                    | 结构的权重，放在指数位置，通常取1                            |


- SSIM数值的范围：对于SSIM的三个组件，分别利用基本不等式以及柯西不等式的知识，可以得出三个组件的范围都是[0,1]，在权重分别为α，β，γ的情况下，三者相乘得到总损失依然为[0,1]，**即SSIM数值的范围为[0,1]**

### Q2：

- 如上所述，SSIM的计算由三个组件构成：**亮度，对比度，结构**，即SSIM对图片的考虑主要从亮度，对比度，结构三个方面

### Q3：

- PSNR考虑的是**像素级别**的差异，只关注像素之间的不同，而SSIM考虑的是**结构级别**的差异，更关注图像结构层面上的不同，是一个更宏观的特征，更符合人们视觉的直观感受
